# my_agent_setup

내가 직접 만들고, 이유를 설명할 수 있는 Claude Code 하네스 설정 묶음이에요.
큰 설정을 통째로 설치하지 않고, 실제로 불편했던 것만 부품으로 하나씩 추가해요.

## 원칙
- **작게**: 이유를 한 줄로 못 쓰는 부품은 넣지 않는다.
- **증거로**: 부품마다 어떤 불편에서 나왔는지 `docs/journal/`에 남긴다.
- **역설계로**: 다른 레포(ECC 등)의 부품은 돌려보고 → 뜯어보고 → 다시 만들고 → 비교한다. 기록은 `docs/reverse/`.

## 부품 목록

| 부품 | 왜 넣었나 | 순정과 차이 |
|---|---|---|
| `CLAUDE.md` 설명 방식 규칙 | EDA 결과가 전문가 말투라 이해하지 못함 | 순정은 사용자 수준을 모름 → 입문자 기준 + 결론 3줄 먼저 |
| `CLAUDE.md` 합계 검증 규칙 | Claude가 합계 비교로 자기 실수를 고친 걸 보고, 매번 하게 하고 싶음 | 순정은 할 때도 있고 안 할 때도 있음 → 항상 |
| `CLAUDE.md` 진행 방식 규칙 | 단계마다 멈추면 꼼꼼하지만 1시간 걸림 | 기본은 끝까지, 멈출지는 내가 정함 |
| `AGENTS.md` | 다른 에이전트 도구에서도 같은 규칙 쓰기 | 규칙은 CLAUDE.md 한 곳에만 |
